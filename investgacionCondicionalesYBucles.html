Estructuras de Control de Flujo (Explicación Estática)

Estas estructuras permiten que los programas tomen decisiones y repitan tareas en función de condiciones.

1. Condicionales (Decisión)

Estas estructuras evalúan una condición y, basándose en si es verdadera o falsa, ejecutan un bloque de código específico.

if-else

Si la condición del `if` es verdadera, se ejecuta el primer bloque. Si es falsa, se ejecuta el bloque `else`.

// Ejemplo: Verificar si hace calor const temperatura = 28; if (temperatura > 25) { // Bloque ejecutado si la condición es VERDADERA (28 > 25) console.log("¡Hace calor! Necesitas aire acondicionado."); } else { // Bloque ejecutado si la condición es FALSA console.log("El clima es agradable o frío."); }

Resultado esperado: ¡Hace calor! Necesitas aire acondicionado.

if-elseif

Permite evaluar múltiples condiciones secuencialmente. Se ejecuta el primer bloque cuya condición sea verdadera, ignorando el resto.

// Ejemplo: Asignar una calificación const nota = 85; if (nota >= 90) { console.log("Calificación: A (Excelente)"); } else if (nota >= 80) { // Esta condición se evalúa y ejecuta (85 >= 80) console.log("Calificación: B (Sobresaliente)"); } else if (nota >= 70) { console.log("Calificación: C (Aceptable)"); } else { console.log("Calificación: D (Necesita mejorar)"); }

Resultado esperado: Calificación: B (Sobresaliente).

switch

Compara una única expresión con varios valores (`case`). El `default` se ejecuta si ninguna coincide. El `break` es crucial para salir del `switch`.

// Ejemplo: Mensajes según el día const dia = "Miércoles"; let mensaje = ""; switch (dia) { case "Lunes": mensaje = "Empezando la semana."; break; case "Viernes": mensaje = "¡Casi fin de semana!"; break; default: // Este bloque se ejecuta si dia no es Lunes ni Viernes mensaje = "Día intermedio de la semana."; break; } console.log(mensaje);

Resultado esperado: Día intermedio de la semana.

2. Bucles (Repetición)

Los bucles ejecutan un bloque de código repetidamente mientras una condición se cumpla.

while

El bucle `while` verifica la condición **antes** de cada iteración. Si la condición es falsa inicialmente, nunca se ejecuta.

// Ejemplo: Contar de 0 a 3 let contador = 0; let output = "Conteo con while: "; while (contador < 4) { // Condición se evalúa al inicio output += contador + " "; contador++; // Asegura que el bucle termine } console.log(output);

Resultado esperado: Conteo con while: 0 1 2 3

do-while

Garantiza que el cuerpo del bucle se ejecute **al menos una vez** antes de verificar la condición al final.

// Ejemplo: El valor inicial (5) hace la condición final falsa (5 < 5), pero se ejecuta una vez. let i = 5; let output = "Conteo con do-while: "; do { output += i + " "; // Se ejecuta aquí (i=5) i++; // Ahora i es 6 } while (i < 5); // Condición es falsa (6 < 5) console.log(output);

Resultado esperado: Conteo con do-while: 5

for

Ideal cuando se conoce el número exacto de iteraciones. Agrupa la inicialización, la condición de parada y el incremento.

// Ejemplo: Recorrer 4 veces let output = "Iteraciones: "; for (let j = 0; j < 4; j++) { output += `Paso ${j+1} `; } console.log(output);

Resultado esperado: Iteraciones: Paso 1 Paso 2 Paso 3 Paso 4

forEach (Iteración de colecciones)

Es una manera simplificada de iterar sobre cada elemento de una colección (como un array) sin tener que gestionar el índice manualmente.

// Ejemplo: Procesar elementos de un array const colores = ["Rojo", "Verde", "Azul"]; let output = "Colores: "; colores.forEach(function(color) { output += color + ", "; }); console.log(output);

Resultado esperado: Colores: Rojo, Verde, Azul,
