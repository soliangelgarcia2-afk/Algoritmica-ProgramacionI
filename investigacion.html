1 & 2. Variables vs. Constantes

Variable (Mutable)

Es como una caja abierta. Puedes sacar el contenido y meter algo nuevo.

puntuacion = 10;
puntuacion = 20; // ✅ Permitido

Constante (Inmutable)

Es como una caja sellada. Una vez guardas el valor, no cambia.

PI = 3.1416;
PI = 4; // ❌ Error

8 & 9. Contenedores Docker

Tecnología para empaquetar software y ejecutarlo igual en cualquier máquina.

Pasos Clave para la Ejecución

  1. 1. Definir la Imagen: Crear un archivo `Dockerfile` con las instrucciones del sistema operativo, código y dependencias.
  2. 2. Construir la Imagen: Ejecutar `docker build` en la terminal para generar la imagen binaria (el paquete sellado).
  3. 3. Ejecutar el Contenedor: Usar `docker run` para crear y encender una instancia aislada y temporal de esa imagen.
Terminal
$ docker run --name mi-web -d -p 8080:80 nginx
Unable to find image 'nginx:latest' locally
